How do I get this into my calendar?

          

            
Google Calendar — Settings → Import & export → Import, pick the file and the target calendar.

            
Outlook — File → Open & Export → Import/Export → Import an iCalendar (.ics) file. Choose Import to merge it into your calendar.

            
Apple Calendar — File → Import, or just double-click the downloaded file.

            
Re-running this tool on an updated table produces the same event IDs, so importing again updates the events instead of duplicating them — as long as the calendar name stays the same.
